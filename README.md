# Color Lines

Color Lines (Lines 98) engine in Python (Numba) scoring 724 points on average.

## Install

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Play

Run the game:

```bash
python interactive.py
```

The arrow visualizes the recommended move generated by `policy.py`. On the first move, it takes a few seconds for the policy to compile, which freezes the game. Wait until the arrow is displayed before trying to make a move.

## Files

- `engine.py` — game engine
- `env.py` — engine variant exposing `next3`
- `policy.py` — move-selection policy
- `interactive.py` — pygame GUI
